Profiling Report 用户指南

在 MSTT 中打开 .npu-rep 算子性能报告后，用时间线与侧栏回答：整体耗时多久、哪些 PIPE 更忙、哪一段最值得优化。

打开报告 界面布局 缩放与平移 搜索与选中 度量 显示控制 报告侧栏 快捷键 尚未覆盖

1. 打开报告

  • 在 MSTT 性能结果树中打开 .npu-rep 文件（产品正式扩展名），或在资源管理器中右键该文件，选择「打开性能分析报告 / Open Profiling Report」。
  • 插件会挂载 Profiling Report 面板；.bin 仍由 MindStudio Insight 打开。
  • 也可打开独立的 Chrome Trace .json（无 CSV 包时侧栏分析会隐藏）。

2. 界面布局

  • 顶栏 — 搜索、缩放、快捷键说明、适应窗口、度量、显示控制、报告侧栏开关、用户指南。
  • 主区 — 概览刷选条 + 泳道时间线（左侧泳道标签，右侧事件块）；支持框选多选。
  • 右侧栏 — 「报告统计」侧栏（有数据时显示）：摘要卡片、计算负载分析（PIPE）、内存负载分析（拓扑）等。
  • 底栏详情 — 选中 1 个事件时显示名称与起止时间等；多选（≥2）时展示选中汇总。

3. 缩放与平移

  • 滚轮 — 纵向滚动泳道。
  • Ctrl / Cmd + 滚轮（触控板捏合同路径）— 以光标为中心缩放时间轴。
  • 平移时间 — Shift + 滚轮、触控板双指横向，或 Ctrl / Cmd + 左键拖拽。泳道上的普通拖拽用于框选，不会平移时间轴。
  • 顶栏缩放滑条与 适应窗口 — 缩放到可见全量时间范围。
  • 键盘：W/S 缩放，A/D 平移。

4. 搜索、悬停与选中

  • 搜索 — 顶栏按事件名过滤高亮。
  • 悬停 — 提示名称、开始、持续、结束；相邻空档可显示瞬时 Δt（默认模式）。
  • 单击 — 选中事件并打开详情；单击空白处取消选中。
  • 框选 — 在泳道上拖拽拉出选区，多选与选区相交的叶子事件；Shift + 单击可追加/移出当前选中；Shift + 拖拽可将新框选并入已有选中。
  • 右键菜单 — 可重置缩放、置顶行等；置顶行（以及左侧槽位图钉、全局 Shift + P）固定的是叶子泳道行，不是单个事件块。Shift + P 切换当前悬停的叶子泳道是否置顶。
  • Alt + 单击 — 设置度量锚点（不改变选中）；按住 Alt 悬停可测到另一事件边或光标。

5. 度量模式

顶栏度量（卡尺图标）进入时间范围度量：在泳道上拖出区间，显示阴影带与 Δt。 度量模式下普通拖拽用于拉区间，不会框选。度量只是本地面板叠加，不会按区间重算侧栏统计。再次点击度量按钮退出。

6. 显示控制

顶栏显示控制图标打开同名浮层：

  • 任务显示单位 — 「时间（自动）」或（有频率数据时）「CPU 时钟周期」。这是时间轴/任务块的显示单位，与 Card 槽位上的「利用率 / 时钟周期」指标切换不是同一控件。
  • 任务连接层级 — 依赖图向前/后走多少跳；-1 表示不限跳数（每侧有上限）。图标旁的问号为字段说明，不是本指南。

7. 报告侧栏

侧栏标题为「报告统计」（有分析数据时显示；顶栏「报告」图标可开关）。堆叠内容（缺数据的块会隐藏）大致为：

  • 摘要卡片 — 整体耗时、算力、带宽、并行利用率等。
  • 计算负载分析 — PIPE 占用图；MIX 算子可切换 Cube / Vector；详情打开计算相关 CSV。
  • 内存负载分析 — 内存拓扑图（有可绘制数据时）；支持全屏与详情（内存 CSV）。
  • 更多 — 打开硬件信息详情（不是计算/内存详情的入口）。
  • CANNBot — 报告壳与计算/内存等章节可有图标入口，将当前章节数据发给 CANNBot 分析（需主机已安装 CANNWork ≥ 2.0.0 并登录）。

8. 快捷键说明

顶栏键盘图标打开「快捷键说明」浮层，列出鼠标 / 键盘 / 组合操作（含触控板示意）。 完整手势以浮层为准，此处不重复逐条。

9. 本指南尚未覆盖

依赖连线的完整交互（无依赖数据时曲线可能为空）、源码 / 缓存等次级页签（界面上可能禁用）、Roofline 与部分后续能力仍在后续阶段或需宿主能力开关；界面上若未出现，表示当前报告或版本尚未提供。

正式报告扩展名为 .npu-rep。工程样例中的经典 .rep 仅用于开发与测试，不是插件对外支持的产品别名。
