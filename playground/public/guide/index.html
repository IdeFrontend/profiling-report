Profiling Report 用户指南

在 MSTT 中打开 .npu-rep 算子性能报告后，用时间线与侧栏回答：整体耗时多久、哪些 PIPE 更忙、哪一段最值得优化。

打开报告 界面布局 缩放与平移 搜索与选中 度量 显示控制 报告侧栏 快捷键 尚未覆盖

1. 打开报告

在 MSTT 性能结果树中打开 .npu-rep 文件（产品正式扩展名）。插件会挂载 Profiling Report 面板； .bin 仍由 MindStudio Insight 打开。也可打开独立的 Chrome Trace .json（无 CSV 包时侧栏分析会隐藏）。

2. 界面布局

  • 顶栏 — 搜索、缩放、快捷键说明、适应窗口、度量、显示控制、报告侧栏开关、用户指南。
  • 主区 — 概览刷选条 + 泳道时间线（左侧泳道标签，右侧事件块）。
  • 右侧栏 — 报告统计、PIPE 占用等（有数据时显示）。
  • 底栏详情 — 选中事件后显示名称与起止时间等。

3. 缩放与平移

  • 滚轮 — 纵向滚动泳道。
  • Ctrl / Cmd + 滚轮（触控板捏合同路径）— 以光标为中心缩放时间轴。
  • 拖拽 / Ctrl + 左键拖拽 / 触控板双指横向 — 平移时间。
  • 顶栏缩放滑条与 适应窗口 — 缩放到可见全量时间范围。
  • 键盘：W/S 缩放，A/D 平移。

4. 搜索、悬停与选中

  • 搜索 — 顶栏按事件名过滤高亮。
  • 悬停 — 提示名称、开始、持续、结束；相邻空档可显示瞬时 Δt（默认模式）。
  • 单击 — 选中事件并打开详情；单击空白处取消选中。
  • Alt + 单击 — 设置度量锚点（不改变选中）；按住 Alt 悬停可测到另一事件边或光标。

5. 度量模式

顶栏度量（卡尺图标）进入时间范围度量：在泳道上拖出区间，显示阴影带与 Δt。 度量只是本地面板叠加，不会按区间重算侧栏统计。再次点击度量按钮退出。

6. 显示控制

顶栏图层图标打开「显示控制」：

  • 任务显示单位 — 「时间（自动）」或（有频率数据时）「CPU 时钟周期」。
  • 任务连接层级 — 依赖图向前/后走多少跳；-1 表示不限跳数（每侧有上限）。图标旁的问号为字段说明，不是本指南。

7. 报告侧栏

  • 摘要 — 整体耗时、算力、带宽、并行利用率等（有数据时显示）。
  • PIPE — 各 PIPE 占用；MIX 算子可切换 Cube / Vector。
  • 更多 — 计算负载、内存负载、硬件信息等详情入口。
  • 侧栏开关在顶栏最右侧附近的「报告」图标；无分析数据时可能隐藏。

8. 快捷键说明

顶栏键盘图标打开「快捷键说明」浮层，列出鼠标 / 键盘 / 组合操作（含触控板示意）。 完整手势以浮层为准，此处不重复逐条。

9. 本指南尚未覆盖

依赖连线完整交互、多选汇总、右键菜单、源码 / 缓存等次级页签、Roofline 与内存拓扑图等仍在后续阶段；界面上若未出现，表示当前报告或版本尚未提供。

正式报告扩展名为 .npu-rep。工程样例中的经典 .rep 仅用于开发与测试，不是插件对外支持的产品别名。
