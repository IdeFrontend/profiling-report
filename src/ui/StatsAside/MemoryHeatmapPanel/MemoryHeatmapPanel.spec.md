# MemoryHeatmapPanel

| spec-id-prefix |
|----------------|
| PR-HEAT-*      |

biprof **§11.2.3.2 Memory Utilization Heatmap** — the right-hand panel of the memory-topology **全屏** overlay. Its own surface beside [`MemoryTopologyPanel`](../MemoryTopologyPanel/MemoryTopologyPanel.spec.md): the diagram shows the path, this panel shows one unit's allocation (DATA-49).

## Inputs

**Data SSOT:** [docs/views/memory-topology.md § Memory Utilization Heatmap](../../../../docs/views/memory-topology.md).
**Carrier:** `MemoryHeatmapModel` ([`src/domain/types.ts`](../../../domain/types.ts)) — `units: { id, views[] }[]`; each view carries Layout lattice + capacity; **capability `memoryHeatmap`**, independent of `memoryDiagram` / `archDiagram`.
**Builder:** [`emulateMemoryHeatmap.ts`](../../../adapters/emulateMemoryHeatmap.ts) (`memoryHeatmapFromTexts`) — Layout+Cells only ([DATA-50](../../../../docs/context/decisions/DATA.md)); wired in [`adaptEmulate`](../../../adapters/adaptEmulate.ts) / compute path. No UbRw path.

**model** — optional `MemoryHeatmapModel` (`units[].views[]`). **selectedUnit** — host-owned tab. Multi-view units (AIV0/AIV1 UB) keep a **local** view selector (PR-HEAT-012) — same `SourcePillSelect` chrome as the Source tab. Optional **locale**.

**Filled by:** one view per Layout row — lattice cols/rows from `Width`×`Height`, capacity from [DATA-51](../../../../docs/context/decisions/DATA.md); `OutsideDeclared` badge. Missing units blank ([UI-60](../../../../docs/context/decisions/UI.md) — no L2Cache tab).

## Outputs

**select-unit** — a tab click names the unit the host should show; the host writes it back as **selectedUnit**, so the tab strip, the diagram's selected unit and the panel body cannot disagree (PR-MEMTOP-022).

## Behavior

1. **Five tabs, always** (PR-HEAT-001): `L1 | UB | L0A | L0B | L0C` ([UI-60](../../../../docs/context/decisions/UI.md) — no L2Cache), in that order, `role="tablist"` / `role="tab"` with `aria-selected` and a **roving tabindex** (only the selected tab is in the tab order; Arrow / Home / End move the selection — PR-HEAT-009). A unit the model has no source for is **not** omitted — the tab stays and its body blanks (behavior 5), because the strip is a fixed five.
2. **Legend** (PR-HEAT-002 / PR-HEAT-014): title **Access Count** / **访问次数** above a single continuous Free→Used blue gradient strip (`#AFC6FE` → `#3D64AD`) with end labels **`0`** and the active view's **max access count** (comma-grouped) — #200. Hovering the strip shows a fixed **10%** brush window (center follows the pointer vs the painted track, clamped to ±half-brush so side pads capture **`0 – 0`** / **`max – max`**; range label coerces to 0…max) with the access-count span under the window and a **match-count tip above** the window (`{n} cells` / `{n} 个块`, only when ≥1 cell is in range); `0` / max end labels fade as the window approaches; out-of-range cells are dimmed by a **Canvas 2D mute veil lattice** (`#2C2C2C` cells, gaps clear so board `#303f5e` grid lines show, **200ms** opacity fade, interruptible) under a **bright Canvas 2D** layer of in-range cells (membership snaps while sliding; no per-cell color transition); the browsing window itself mounts/unmounts **instantly** (no animation). Hit band is 22px tall (16px window + 3px pad above/below) and ±5% wide of the strip on each side. While the brush is active the legend strip fades a `#2C2C2C` mute overlay (same 200ms, interruptible) and keeps only occupancy bands bright (intensities present on ≥1 cell, each ≥**3px** wide, merged when they overlap). Clears on leave (mute/occ opacity fade out). Not discrete Used/Free swatches, not `%` tick clutter.
3. **Body** (PR-HEAT-003): the **block lattice** is painted on **Canvas 2D** (base canvas under the mute veil + bright canvas above it) — one rounded rect per active `view.blocks` entry, row-major, `view.columns` × `view.rows` (Layout `Width`×`Height`) square cells, sized to fit the leftover body (PR-HEAT-011) — then the selected view's name (behavior 5) and the capacity caption **under** it. Each cell paints `heatFill(intensity)` as an RGB lerp from Free `#AFC6FE` (0) to Used `#3D64AD` (1) where `intensity ∈ [0,1]` is `(Read+Write)/viewMax` (#200); no per-cell DOM spans. Never a divider band. Column and row counts bind from the active view (not restated in CSS). The frame repeats the view's **name** under its grid (Visual), so the body carries it there — never a second copy *above* the lattice. The five tabs share **one** `role="tabpanel"` body, named by the active tab. Hover uses a **single grid `pointermove` + geometry hit-test** (swimlane-style) and a non-layout zoomed overlay tile — not per-cell `pointerenter` — and opens the SA cell tip (PR-HEAT-013).
4. **Metric** (PR-HEAT-004 / PR-HEAT-004b): centred **below** the grid (under the unit name). Paint `Total: {n} / Used: {n} / Free: {n}` from the active view's capacity fields ([DATA-51](../../../../docs/context/decisions/DATA.md)). Byte counts share one unit chosen from Total (`B` / `KB` / `MB`) with a space before the unit (`256 KB`) so Total/Used/Free never mix units (#201). Omit when Total is unknown — never a placeholder, never `已用指令条数`.
5. **Unit name** (PR-HEAT-010): the selected view uses the same label as the view selector (`{ownerName} {memoryName}` when known, otherwise `{memoryName}`). **Multi-core** packs prepend `Core {coreId} ·` (#198), including a view with no owner (`Core 0 · UB`), so switching cores changes the caption. Diagram tab words (`AIV × 2 UB`) are only the single-core, no-owner fallback. Centred between the grid and the metric at `19px` `#e7e7e7`, `31px` under the grid. Absent with the blank body (behavior 6) — no name without a grid. `coreId` comes from the pack (DATA-50); never invent one. Single-core packs (one distinct `coreId` across all views) omit the Core prefix.
6. **Blank state** (PR-HEAT-005): a tab whose unit is absent from `model.units` shows the empty line and no grid; it does **not** show an all-empty grid, which would read as "measured, nothing allocated" rather than "no source".
7. **Selection is the host's** (PR-HEAT-006): the active tab is `selectedUnit`; a click emits **select-unit** and changes nothing else. Re-clicking the active tab emits again — the host treats it as a no-op (PR-MEMTOP-023).
8. **Omit itself** (PR-HEAT-007): with no `model`, or a model with no units, the panel renders nothing at all (no tab strip, no legend). The host also gates the mount on the capability, so this is the second guard, not the first.
9. **Grid a11y** (PR-HEAT-008): the grid is one `role="img"` with a label summarising `{used} / {total}` used blocks (#199), i.e. the cells are not read out one by one — 416 anonymous cells are noise, and the counts are what the picture says.
10. **Short column fit** (PR-HEAT-011): the tab strip, legend, view-bar band, unit name and metric keep their frame sizes; the body is the size container and the grid picks a square cell = `min(width-fit, height-fit)` (height budget minus the title/metric footer) so the Layout lattice never overflows and **never opens a scrollbar**. Spare height falls below the metric. The body clips (`overflow: hidden`).

## Acceptance Criteria

1. **PR-HEAT-001** — Renders the five tabs in order (`L1`, `UB`, `L0A`, `L0B`, `L0C`) as `role="tab"` buttons inside a `role="tablist"`, all five present even when `model.units` carries fewer (a unit with no source keeps its tab). No `L2Cache` tab ([UI-60](../../../../docs/context/decisions/UI.md)).
2. **PR-HEAT-002** — Renders a centred legend: **Access Count** title, one Free→Used blue gradient strip (8px tall, `#AFC6FE` → `#3D64AD`), end labels `0` and the formatted max access count (#200).
3. **PR-HEAT-003** — Paints one Canvas 2D cell per active `view.blocks` entry in carrier order with continuous Free→Used blue fill from intensity (#200) on the base canvas (bright canvas stays empty until brush). The grid is one `2px` `#6e798d` frame around a `#303f5e` board with a `2px` inset and `2px` gaps — no per-cell DOM spans or divider band.
4. **PR-HEAT-004 / PR-HEAT-004b** — With `totalBytes`/`usedBytes`/`freeBytes` on the active view, shows `Total: {n} / Used: {n} / Free: {n}` (shared unit + space before unit, #201) and binds `--pr-heat-cols` / `--pr-heat-rows` from that view. Omits the caption when Total is unknown. No instruction-count metric.
5. **PR-HEAT-005** — A selected unit absent from the model shows the empty line and **no** grid.
6. **PR-HEAT-006** — The tab named by `selectedUnit` is the only `aria-selected="true"` tab; a click on any tab emits `select-unit` with that unit and does not change the rendered selection by itself.
7. **PR-HEAT-007** — Renders nothing when `model` is null/undefined or has no units.
8. **PR-HEAT-008** — The grid is a single `role="img"` whose accessible name reports `{used} / {total}` used blocks (#199), and its cells are not individually exposed.
9. **PR-HEAT-009** — The strip is a complete `tablist`: exactly one tab has `tabindex="0"` (the selected one, the rest `-1`; with no selected unit the **first** tab carries it, so the strip is never unreachable by keyboard), `ArrowRight` / `ArrowLeft` move the selection to the next / previous unit and **wrap** at both ends, `Home` / `End` jump to the first / last unit, any other key is left to the platform, and the click handler is unchanged — the tab click and the arrow keys both emit **select-unit** and the panel never moves the selection itself. The five tabs share one `role="tabpanel"` body, `aria-labelledby` the selected tab. The labels fill the column to the pixel, so the tabs never shrink or wrap: each keeps its own width and the strip scrolls horizontally instead (invisible while they fit).
10. **PR-HEAT-010** — With a drawable unit, the body's text content is exactly two lines in this order: the view title (same string as the view option: `{ownerName} {memoryName}` or bare `memoryName`; multi-core packs prepend `Core {coreId} · ` — e.g. `Core 0 · AIV0 UB` / `Core 0 · UB`; diagram tab words such as `AIV × 2 UB` only for single-core packs with no owner), `19px` `#e7e7e7`, centred, then the metric; the name is absent (with the grid) for a blank unit, and no unit name is rendered **above** the grid.
11. **PR-HEAT-011** — The body is the size container (`container-type: size`); the grid picks `--pr-heat-cell: min(width-fit, height-fit)` with a footer budget for title + metric. Height-fit subtracts the same **8px** frame (padding+border) as width-fit so the `#6e798d` stroke is not clipped. The body has `overflow: hidden` (no scrollbar). Tabs, legend, the always-reserved view-bar band, and the `OutsideDeclared` badge stay outside the body so they cannot clip the lattice. The grid binds both `--pr-heat-cols` and `--pr-heat-rows`, and its frame is `5px`-rounded.
12. **PR-HEAT-012** — When the active unit has more than one view (multi-core UB), a `SourcePillSelect` in the reserved view-bar band switches the lattice / name / capacity among those views; option labels include `Core {coreId} ·` when the pack has more than one distinct `coreId` (#198). The shared pill menu scrolls when many cores are listed, with dark `.pr-root`-matched scrollbar chrome (teleported outside `.pr-root`). Single-view tabs keep the empty band (same lattice height) and mount no select.
12. **PR-HEAT-012** — When the active unit has more than one view (multi-core UB), a `SourcePillSelect` in the reserved view-bar band switches the lattice / name / capacity among those views. Single-view tabs keep the empty band (same lattice height) and mount no select.
13. **PR-HEAT-013** — Grid `pointermove` hit-tests the pointer to a block index (`heatHitTest.ts`; seams stay on the left/top cell). A single absolute overlay paints a **zoomed** filled tile (+4px each side, centered, same `heatFill`) above the cell (cells keep fixed size — no margin/size grow, no per-cell hover class). Tip rows: **Start Address** (`BaseAddress + index×CellSize` as `0x…` hex), **Cell Size** (`{n} Bytes`), **Accesses Count** / **访问次数** (comma-grouped `accessCount` = `Read+Write`), teleported with EventTooltip chrome + `placeFixedTip`. Same-index moves chase tip xy only; tip/highlight clear on grid leave or view change — no thrash, no enter fade. Capacity caption stays under the grid — never put access/instruction counts there ([DATA-51](../../../../docs/context/decisions/DATA.md)).
14. **PR-HEAT-014** — Hovering the legend gradient mounts a 10%-wide brush whose center follows the pointer vs the painted track (clamped to ±half-brush; side pads yield coerced `0 – 0` / `max – max`); the hit band is 22px tall (16px window + 3px pad above/below) plus ±5% horizontal pads, not only the 8px painted strip; the access-count span sits under the window and moves with it; a match-count tip sits **above** the window and shows only when ≥1 cell is in range; `0` / max ticks fade toward opacity 0 as the window approaches either end; heatmap dim uses a `#2C2C2C` **Canvas 2D veil lattice** (gaps clear → board grid lines, 200ms opacity, interruptible) plus a bright **Canvas 2D** layer of in-range cells (slide membership snaps; brush chrome appears/disappears instantly); the legend strip fades a `#2C2C2C` mute overlay with bright occupancy bands (≥3px per unique intensity, merged on overlap, same interruptible 200ms opacity fade); leave clears brush chrome immediately and fades veil/occ out. No click-to-pin.

## Visual

Dark-only: panel `#262626` (the topology card's surface, not `--pr-bg-panel`), tab strip ruled on `#333333`, active tab on the short white bar. The panel is mounted as the 全屏 overlay's right column (**400px**, the sketch's ~398px band) and meets the diagram with **no** stroke between them — the frame's own boundary is the panel's `#262626` against the overlay's literal `#1a1a1a` (not `--pr-bg-aside`, which light-theme remaps), not a divider line. Every value below is measured off the sketch crop (`visual/heat-panel.png`, a 1:1 crop of the 7680×4320 frame, i.e. **4×** — so sketch px ÷ 4 = frame px).

Shipped block order: tab strip → rule → legend → **reserved view-bar** (multi-view pill or empty band, PR-HEAT-012) → optional `OutsideDeclared` badge → body (`grid` → selected view name → `Total / Used / Free` caption). Nothing sits *above* the lattice inside the body except the grid itself.
