# Swimlane sample traces

Chrome Trace–style `merged_swimlane.json` files for local rendering and smoke tests.

| File | Source | Size | Events |
|------|--------|------|--------|
| `compressor_testDD_merged_swimlane.json` | PyPTO-data-compressor `testcase/testDD` | ~35 KB | ~131 |
| `boot_mock_merged_swimlane.json` | PyPTO Toolkit boot-mock rundata | ~1.3 MB | ~5083 |
